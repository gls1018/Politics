## 6. 总结

### 6.1 马原



马原分为三个部分.

- 马哲
- 政经
- 科社



其中马哲可以分为四个部分

- 辩证唯物论
- 唯物辩证法
- 认识论
- 唯物史观



唯物论回答的是世界是什么的问题. 世界是物质的，还是精神的?



辩证法回答的是物质世界是怎样存在的, 是孤立片面静止的, 还是联系的，永恒发展的.



认识论回答的是, 在唯物论和辩证法的基础上, 我们该如何去认识这个世界.



唯物史观回答的是人类社会或者叫人类历史，这种特殊的物质他有什么样的的发展规律.
